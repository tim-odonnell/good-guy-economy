# US economy source catalog — SEARCH this file, never read it whole

Built and link-tested from this machine on 2026-10-09: 210 sources + 100 extra FRED
series. You are NOT limited to this list — it is a head start. If you find a good
new source, add it to `sources.md`.

## How to use
- Search by topic word: `grep -i housing references/economy-sources.md`
  (also try: jobs, inflation, tariffs, fed, recession, history, layoffs, rss, api …)
- Fetch with `econ-fetch URL` (short readable text; `--grep WORD` to find the
  number you need; `--links WORD` to find the newest release link on a page).
- FRED series below: `econ-history latest <ID> [--transform pc1|chg]`, or curl.

## Access tags (tested 2026-10-09)
- **[FETCH]** works with `econ-fetch`. **[FETCH-THIN]** loads, but the numbers are
  drawn by JavaScript — use `--links` to find the PDF/CSV/release, or the browser tool.
- **[BROWSER]** blank without JavaScript — use the browser tool.
- **[BLOCKED]** refuses scripts (paywall/bot wall). Don't spend turns on it; the
  line says what to use instead. Sites change: if a [FETCH] fails, log it in wanted.md.
- **[OPINION]** in the description = analysis/forecasts, never facts.
